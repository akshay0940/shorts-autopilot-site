Privacy policy

shorts-autopilot is used only by its owner, on the owner's own Google account.

  • Data accessed: video files in the owner's Google Drive folders that the tool is set up to use.
  • How it is used: the videos are downloaded temporarily, text is added, and the result is uploaded back to the owner's Google Drive. Temporary copies are deleted when processing ends.
  • Sharing: no data is sold, shared with third parties, or used for advertising.
  • Storage of credentials: access tokens are stored privately by the owner and can be revoked at any time at myaccount.google.com/permissions.

Google API use complies with the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via the YouTube channel @akshaychucklesshorts.
